# 小俣歯科医院 インプラントLP

山梨県都留市・小俣歯科医院のインプラント治療向けランディングページ（静的サイト）です。
画像に依存せず、イラストはすべてインラインSVGで実装しています。外部依存は Google Fonts のみです。

## ファイル構成

```
index.html   … LP本体（構成・文言・インラインSVG）
styles.css   … スタイル（配色・レスポンシブ・アニメーション）
script.js    … リンク差し替え（CONFIG）・スクロールフェードイン
README.md    … 本ファイル
```

## ローカルでの確認方法

外部サーバーは不要です。以下のいずれかで確認できます。

- `index.html` をブラウザで直接開く
- もしくは簡易サーバーを起動：
  ```bash
  python3 -m http.server 8000
  # ブラウザで http://localhost:8000 を開く
  ```

スマホ表示は、ブラウザの開発者ツール（デバイスモード）で幅640px以下にすると、
下部固定の予約バーが表示されます。

## プレースホルダ差し替え箇所

公開前に、以下の「要記入」項目を確定して差し替えてください。

### 1. リンク先（`script.js` の `CONFIG`）

```js
const CONFIG = {
  RESERVE_URL: "PLACEHOLDER_RESERVE_URL", // ← Web予約システムのURL
  LINE_URL:    "PLACEHOLDER_LINE_URL",    // ← LINE公式アカウントのURL（例: https://lin.ee/xxxx）
  TEL:         "0554430889",              // 電話番号（確定済み）
};
```

> 未設定（PLACEHOLDERのまま）でもページは崩れません。
> その場合、Web予約／LINEボタンは自動的に電話発信へフォールバックします。

### 2. 本文中の「要記入」テキスト（`index.html`）

`<!-- 要記入：... -->` コメントと、`class="placeholder"` の注記を目印にしています。

- [ ] 院長名・経歴（「海外で学んだ」具体内容を **事実で正確に**）… `#trust` セクション
- [ ] 費用の税込／税別表記 … `#worry`・`#cost` セクション
- [ ] インビザライン・ホワイトニングの費用 … `#other` セクション
- [ ] Web予約URL／LINE ID … 上記 `CONFIG`

## 医療広告ガイドラインについて（実装で維持している点）

- 効果の断定・最上級・比較優良・体験談での効果保証は記載していません。
- インプラント費用（**1本あたり40万円〜・自由診療・保険適用外**）、
  リスク・副作用、「個人差があります」の記載を保持しています。
- 経歴・資格は事実に基づき記載する前提です（プレースホルダ）。誇大表現にしないでください。

文言を追記・修正する際も、上記の点を必ず維持してください。

## デプロイ手順の概要

> **本番公開は院長の承認後に行ってください。** 本リポジトリは自動デプロイを設定していません。

静的サイトのため、以下のいずれのホスティングでも公開できます（例）。

- **GitHub Pages**: リポジトリの Settings → Pages → Branch を指定して公開
- **Cloudflare Pages**: プロジェクト作成 → ビルドコマンドなし／出力ディレクトリはルート（`/`）
- **Vercel**: プロジェクト作成 → Framework Preset を「Other」、ビルド設定なしで公開

いずれもビルド工程は不要です（静的ファイルをそのまま配信）。
独自ドメインを使う場合は各サービスのドメイン設定を行ってください。
